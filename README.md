# Darwin Cybersecurity Toolkit V3

A Python cybersecurity toolkit that combines multiple security tools into a single application.

## Features

- Password Checker
- IP Checker
- URL Checker
- Log Analyzer
- Threat Intelligence Lookup
- Incident Tracker
- File Extension Scanner

## Skills Used

- Python
- Lists
- Loops
- Dictionaries
- User Input
- Conditional Statements
- Networking Fundamentals
- Threat Intelligence
- Incident Management
- Security Monitoring

## Future Improvements

- Save incidents to a file
- Password Generator
- Report Generation
- Risk Scoring
- Graphical User Interface (GUI)

## Project Goals

This project was created to combine multiple cybersecurity tools into a single application while practicing Python programming and cybersecurity concepts.
